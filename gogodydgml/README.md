# 배관해결사 홈페이지 (샘플)

하림배관·고고고설비(당근) 사례 분석을 반영한 배관/하수구 서비스업 홈페이지 템플릿입니다.

## 반영된 상위노출 전략

1. **증상별 문서 분리** — 하수구막힘/변기막힘/싱크대막힘을 각각 별도 페이지(`pages/`)로 분리해 세부 검색어마다 노출 기회를 확보
2. **지역+증상 조합 키워드** — `#coverage` 섹션에 "평택 하수구막힘"처럼 지역명+증상 조합 링크 배치 (실제 지역 페이지로 확장 가능)
3. **신뢰 신호** — 사업자정보, 후기 수/평점, 답글, 견적 동의 절차를 전면에 노출
4. **구조화 데이터(JSON-LD)** — `Plumber`, `FAQPage` 스키마 삽입으로 검색결과 리치 스니펫 노출 가능성 확보
5. **모바일 최적화 + 전화 연결(tel:)** — 로컬 서비스업 특성상 클릭→전화 전환이 핵심

## 실제 운영 전 반드시 교체할 항목

`index.html`, `pages/*.html` 안의 아래 항목을 실제 정보로 바꿔주세요.

- [ ] 상호명 ("배관해결사" → 실제 상호)
- [ ] 전화번호 (`010-0000-0000`, `tel:` 링크 포함 전체)
- [ ] 사업자등록번호, 대표자명, 실제 도로명주소
- [ ] `<link rel="canonical">`, `og:url`, `sitemap.xml`의 `example.com` → 실제 도메인
- [ ] 후기 내용 — **실제 고객 후기만 게시** (허위 후기는 표시광고법 위반 소지)
- [ ] `naver-site-verification` 메타태그 — 네이버 서치어드바이저에서 발급받은 코드로 교체

## 로컬에서 확인하는 법

```bash
# 폴더 안에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## Git으로 이력 관리 + 배포하기

이미 이 폴더는 git 저장소로 초기화되어 있습니다.

```bash
git add .
git commit -m "Initial commit: 배관 서비스 홈페이지"

# GitHub에 올리려면 (본인 저장소 URL로 교체)
git remote add origin https://github.com/<사용자명>/<저장소명>.git
git branch -M main
git push -u origin main
```

### 무료로 바로 배포하는 법 (GitHub Pages)

1. GitHub에 push 후 저장소 Settings → Pages
2. Branch를 `main`, 폴더를 `/ (root)`로 설정 후 저장
3. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 로 접속 가능

배포 후에는 **네이버 서치어드바이저**(searchadvisor.naver.com)에 사이트 등록 → 소유 확인 → `sitemap.xml` 제출까지 진행해야 실제로 네이버 검색에 수집됩니다.
