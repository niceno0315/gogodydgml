1. 현장 도착과 첫인상

싱크대 배수구 거름망부터 열어서 확인했는데, 거름망 안쪽에 음식물 찌꺼기가 꽤 쌓여있었습니다. 거름망만의 문제는 아닌 것 같아서 더 안쪽까지 살펴보기로 했어요. 거름망을 들어내도 물이 잘 안 빠지는 걸 보니 안쪽 배관에 원인이 있다는 확신이 들었습니다.

2. 하부장 배관 확인

하부장 안쪽을 열어보니 온수 분배기함 아래로 P트랩이 분리된 채 놓여있었습니다. 배관 연결 상태부터 다시 점검해야 하는 상황이었어요. 좁은 공간에 여러 배관이 얽혀있어서 하나씩 확인하는 데 시간이 좀 걸렸습니다.

3. 내시경으로 원인 확인

내시경 카메라를 배관 안쪽으로 넣어보니 화면이 뿌옇게 흐려질 정도로 이물질이 가득한 게 확인됐습니다. 카메라를 조금 더 밀어 넣을 때마다 화면이 점점 어두워지는 걸 보고 막힌 구간이 생각보다 길다는 걸 알 수 있었어요.

4. 작업 진행과 마무리 확인

확인된 지점부터 이물질을 제거하며 배관 안쪽을 반복해서 세척했습니다. 한 번에 시원하게 뚫리지 않아서 여러 차례 반복해야 했어요. 작업을 마치고 다시 한번 내시경으로 확인해보니, 처음보다 화면이 훨씬 밝고 매끈해진 걸 볼 수 있었습니다.
